# 경남대학교 전력변환연구실 홈페이지

단일 파일 정적 사이트입니다. 서버가 필요 없고 GitHub Pages로 공개합니다.

```
index.html   사이트 본체 (화면 + 내용 데이터 JSON 포함)
.nojekyll    GitHub Pages 설정 (빈 파일, 삭제하지 마세요)
images/      사진·그림 (교수 사진, 구성원 사진, 연구 그림)
files/       CV, 강의자료 PDF
```

## 내용 수정하기 (관리자 모드)

1. 사이트 맨 아래 **[관리자]** 버튼 → 비밀번호 입력
2. 점선 표시된 글자를 클릭해 바로 고칩니다. 목록 항목은 ↑↓(순서) ⚙(모든 필드 편집) ✕(삭제), **+ 항목 추가** 버튼으로 관리합니다.
3. 사진·그림 자리를 클릭하면 파일을 저장소에 올리고 바로 연결할 수 있습니다.
   - **Gallery**: [+ 행사 추가] → 제목·날짜 입력 → [+ 사진 추가]로 사진을 올립니다. 사진이 있는 행사는 첫 화면 '연구실 활동' 띠에도 최근 4장이 자동으로 나옵니다.
   - **장비 사진**: Research 메뉴 아래 '실험실·장비 사진'에서 [+ 사진 추가]. 사진을 올리기 전에는 공개 화면에 '사진 준비 중'으로만 보입니다.
   - 사진은 가로 1600px 이하, 500KB 이하로 줄여서 올리면 페이지가 가볍습니다.
4. **[저장 및 게시]** → 1~2분 뒤 사이트에 반영됩니다. 바로 안 보이면 Ctrl+F5(강력 새로고침).
5. 한/영 내용은 따로 관리합니다. KO 화면에서 고치면 한국어만, EN 화면에서 고치면 영어만 바뀝니다. 영어가 비어 있는 항목은 KO 화면의 글이 대신 보입니다.

관리자 바의 다른 버튼:
- **사이트 설정**: 이메일, 전화, 주소, Google Scholar/ORCID 링크, CV 파일, GoatCounter 코드 등
- **파일로 내려받기**: 현재 내용이 반영된 index.html 저장
- **데이터 백업 / 백업 불러오기**: 내용 전체를 JSON으로 저장·복원
- **방문자 현황**: GoatCounter 통계 화면 열기 (사이트 설정에 코드를 넣은 경우)
- **비밀번호·키 재설정**: 접근 키가 만료됐을 때 새 키 등록

## 처음 한 번: 관리자 설정

관리자 기능은 공개된 주소(`https://…github.io/…`)에서만 동작합니다.

1. GitHub 접근 키 만들기: https://github.com/settings/personal-access-tokens/new
   - Repository access: **Only select repositories** → 이 저장소
   - Permissions → Repository permissions → **Contents: Read and write**
   - 만료일은 원하는 기간으로
2. 사이트 하단 **[관리자]** → 저장소(`계정/저장소명`), 접근 키, 비밀번호(10자 이상) 입력 → **설정하고 게시**

접근 키는 비밀번호로 암호화(PBKDF2 + AES-GCM)되어 index.html 안에 저장되며 원문은 어디에도 남지 않습니다. 비밀번호를 잊으면 복구할 수 없으니, 새 키를 만들어 다시 설정해야 합니다(관리자 설정 블록을 비우고 다시 올리면 초기 설정 화면이 나옵니다).

## 새 파일 올리기

CV처럼 큰 파일은 GitHub 저장소의 `files/` 폴더에 직접 올리고(Add file → Upload files), 사이트 설정의 CV 경로(`files/이름.pdf`)만 바꿉니다. 사진은 관리자 모드에서 바로 올릴 수 있습니다. 담당 과목은 Professor 페이지에서 과목명만 관리합니다.
